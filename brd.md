# Business Requirements Definition - BBMPulse

Goal: Build agentic AI civic closure loop for Bengaluru - Smarter Streets Better Living.

Users: Citizens (Kannada/English, WhatsApp), BBMP Engineers (198 wards)
Problem: 12k pending complaints, 6hr manual triage, 21 day closure, no feedback.

Requirements:
1. Intake via WhatsApp photo+GPS+voice Kannada/English
2. Verification via Granite Vision severity 1-5, fake/duplicate check
3. Routing via GIS to BBMP ward responsibility matrix
4. Tracking SLA 48h pothole, 24h flood with escalation
5. Engagement Kannada/English notifications + safety nudges + closure proof
6. Privacy: blur faces/plates, 90 day retention, human-in-loop for Sev5
7. Built with IBM Bob + watsonx Orchestrate mandatory

Measurable Outcome: 70% triage time reduction, 48hr closure loop.
